                            GETTING STARTED
================================================================================

STEP 1: Database Migration
$ cd nse-academy-api
$ npx prisma migrate deploy

STEP 2: Get X API Credentials
Visit: https://developer.twitter.com/en/portal/dashboard
Copy: API Key, API Secret, Access Token, Access Token Secret

STEP 3: Add Credentials in Admin
URL: https://nseacademy-admin.vitaldigitalmedia.net/admin/plugins/user-manager/marketing/social
1. Click "Add Credential"
2. Enter X handle and 4 credentials
3. Click "Test" ✅
4. Done!

STEP 4: Post Your First Report
1. Click "New Post"
2. Write content (280 chars max)
3. Add media URLs (optional)
4. Click "Post Now"
5. ✅ Check X profile!

OPTIONAL: Enable Auto-Posting
Modify daily-report.service.ts to call:
  this.xService.postReportToX('daily', content, mediaUrls);

================================================================================
                          TROUBLESHOOTING
================================================================================

COMMON ISSUES:

Q: "Invalid credentials" error
A: Verify API keys in X Developer Portal
   Check if app has "Read and write" permissions

Q: Post too long error
A: Keep content under 280 characters
   Remove trailing text if needed

Q: Media upload fails
A: Verify image URL is public
   Check image size (max 5MB)
   Supported: JPG, PNG, GIF, WEBP

Q: Auto-posting not working
A: Verify report is generated and published
   Check credentials are active (isActive = true)
   Review logs: docker logs nse-academy-api | grep marketing

See X_TWITTER_INTEGRATION_GUIDE.md for more details.
